Run on Linux with Python 3.12 and the packages in requirements.txt. Run
python -m pytest -q tests to check the implementation. Open the notebook
with jupyter lab notebooks/experiment_log.ipynb and run cells in order.
Notebook stages archive source hashes and tests, the development pilot,
development data audit, 540 validation fold-and-seed fits, 45 final network
fits and baselines, then independent verification and diagnostics. The source
code implements separate Elman, Jordan and combined-feedback recurrent nets.

The existing Git commits are an archive of completed experiments. Their
commit times are not the original training times. The notebook is idempotent
for existing records and commits only changed stage files. It does not push
unless ML441_NOTEBOOK_PUSH=1 is set in the Jupyter process environment and a
remote named origin is configured. Before each push, review git status and
git diff. Supplied course PDFs, local planning documents, Markdown files,
temporary files and Python caches remain local and are excluded from Git.
